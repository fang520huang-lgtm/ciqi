# 清瓷谱｜清代官窑学习志

一个只聚焦清代景德镇御窑与明确宫廷御用瓷的 React 学习网站。界面基于 shadcn/ui 的开放组件模式构建，内容按朝代、款识、器型、胎釉与权威馆藏实例整理。

## 本地预览

进入项目目录后安装依赖并启动 Vite：

```bash
npm install
npm run dev
```

终端会显示本地预览地址。

## GitHub Pages

仓库包含 `.github/workflows/pages.yml`。在仓库 Settings → Pages 中把 Source 设为 **GitHub Actions**，推送到 `main` 后会自动部署到：

`https://fang520huang-lgtm.github.io/ciqi/`

## 图片与内容来源

- 网站中的实物图片来自 The Metropolitan Museum of Art Open Access，藏品页标注为 Public Domain；每张学习卡都保留馆藏编号和原始记录链接。
- 每个本地图片文件与馆藏号的对应关系见 [`IMAGE_SOURCES.md`](IMAGE_SOURCES.md)。
- 文字资料优先引用故宫博物院、国立故宫博物院、The Met 与 British Museum 的研究或教育资料。
- 详细来源与用途注释见网站“资料来源与注释”部分。

## 编辑边界

- 收录：清代御窑、官窑、大运瓷、奉旨传办和明确宫廷专用款。
- 暂不收录：民窑、外销瓷，以及仅凭款识推定的商品瓷。
- 本站为学习索引，不提供交易估价或仅凭照片的真伪结论。
